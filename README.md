# SealDice Plugins

为[海豹核心](https://github.com/sealdice/sealdice-core)编写的JavaScript插件。\
JavaScript plugins written for [SealDice](https://github.com/sealdice/sealdice-core).

## Build from source

In the repository, run:

```bash
npm i
npm run make <folder-name>     # scaffold for a new plugin
npm run compile <folder-name>  # compile the plugin into JS
```
